### Key Optimizations
- Streaming / DATAFLOW-based CNN pipeline
- Parallel convolution processing with controlled resource reuse
- `reuse16` / `reuse32` architecture for later convolution layers
- Weight and bias storage moved to on-chip BRAM
- Reduced resource usage while maintaining acceptable latency
